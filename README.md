App de Avaliação Física
Este é um aplicativo web simples para gerenciar avaliações físicas de alunos. Ele permite que um professor adicione alunos, registre suas avaliações e visualize o histórico. Os alunos também podem visualizar seus próprios dados.

O aplicativo funciona 100% offline, salvando os dados no navegador do usuário (localStorage).

Estrutura dos Arquivos
index.html: Contém a estrutura principal da página (o esqueleto do app).

style.css: Contém todas as regras de estilo para a aparência do app.

script.js: Contém toda a lógica e funcionalidade do aplicativo, incluindo cálculos, manipulação de dados e interatividade.

Como Usar
Faça o download dos três arquivos (index.html, style.css, script.js).

Coloque todos eles na mesma pasta.

Abra o arquivo index.html em qualquer navegador de internet moderno (como Chrome, Firefox, Edge, etc.).

O aplicativo estará pronto para uso.
